## Operational resilience — NEEDS TRIAGE (not yet scoped)

A category the backlog has not modelled. Sonnet 4.6 if pursued.
- ✅ **Sheets write retry/backoff** `[correctness]` (`sheets.js` `appendRows`): `appendRows` now wraps the `values.append` call in `retryWithBackoff` (bounded: 1 initial + 3 retries, exponential 500/1000/2000 ms). **Idempotency-safe retry scope:** `values.append` is NOT idempotent and the `write_id` guard lives in `index.js` (dedupes across HTTP requests, not inside this loop), so `isTransientAppendError` retries **only** on errors where Google rejected the request before touching the sheet — HTTP 429/503 and 403 rate-limit/quota reasons. Ambiguous failures (post-send timeouts, 500s) propagate un-retried to avoid a silent double-append.
